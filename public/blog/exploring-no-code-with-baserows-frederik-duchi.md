# Exploring No-Code with Baserow's Frederik Duchi

![alt-text-1](/baserow/baserow-host.jpg 'title-1') ![alt-text-2](/baserow/baserow-demo.jpg 'title-2')

This past week, students and tech enthusiasts at our university got a hands-on introduction to the world of no-code databases, thanks to a compelling session led by **Frederik Duchi**, a representative from **Baserow**.

Baserow, for those unfamiliar, is a powerful **open-source no-code platform** that lets users build databases and web applications—all without writing a single line of code. Whether you’re managing a project, organizing a startup, or just looking to tame your data, Baserow has something for you.

### 🧠 The Session: Building in Real-Time

Frederik kicked off the session with a short overview of Baserow’s mission: **democratizing database building and making app development accessible to everyone**.

Then came the live demo where things really clicked.

1. **Creating a Table from Scratch**:
   Frederik started by walking us through how to create a functional database table, explaining each field type (text, dropdown, date, attachment) as he built a content planning tool from scratch.

2. **Building a Website**:
   With a few clicks, he transformed structured data into a simple, functional website interface. No HTML, no CSS just structured logic and configuration. It was a clear demonstration of how non-developers can bring ideas to life quickly.

3. **Automation & API Power**:
   While the interface is no-code, Frederik highlighted that Baserow is developer-friendly, too with REST API access and easy integration with tools like Zapier, Make, and n8n.

### 🎯 Key Takeaways

- **Baserow is a legit alternative to Airtable**, especially for privacy-conscious users thanks to its self-hosting options.
- **No-code doesn’t mean no-power**—Frederik’s demos showed that intuitive UI can coexist with serious backend capability.
- The Baserow community is growing fast, and the open-source foundation means anyone can contribute or customize.

---

This Tech\&Meet gave us a solid look at how no-code tools are changing the way we build, think, and work with data. Big thanks to Frederik and the Baserow team for inspiring us to imagine and create without limits.
